# Вбудований велосипедист

`Sports_Male_04` з бібліотеки **Microsoft Rocketbox Avatar Library**
(https://github.com/microsoft/Microsoft-Rocketbox), ліцензія MIT — див. `LICENSE.md`.

Текстури `m026_body_color.tga` і `m026_head_color.tga` перетворено на JPEG 1024×1024 (`body.jpg`, `head.jpg`);
карти нормалей і відблисків не використовуються. Форма (джерсі, смуга, шорти) перефарбовується в браузері.

Власна модель `assets/rider.fbx` або `assets/rider.glb` має пріоритет над цією.
