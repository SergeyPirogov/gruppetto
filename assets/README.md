# Моделі для 3D-графіки

**Природа** (`nature/`) і **велосипедист** (`rider/`) — CC0-моделі Quaternius у спільному мультяшному стилі,
див. `CREDITS.md`. Велоформу (джерсі, шорти, шкарпетки, взуття) застосунок малює на базовому тілі сам,
у кольорах з профілю. Без цих тек сцена повертається до вбудованих форм.

## Свій велосипедист

Файл `rider.glb` або `rider.fbx` у цій теці має пріоритет над `rider/`.
Якщо жодного файлу моделі немає, використовується райдер, збудований кодом (`js/rider-procedural.js`): джерсі, шорти, шкарпетки, взуття, шолом і окуляри. Щоб використовувати його навіть за наявності файлу, додайте в `rider.json` `"model": "procedural"`.

Покладіть сюди файл **`rider.fbx`** (наприклад, прямо з Mixamo) або **`rider.glb`** — будь-якого персонажа людини
зі скелетом (rigged humanoid). Конвертувати нічого не треба.
Power Up сам розверне його по ходу руху, підбере розмір, посадить на велосипед, покладе руки на кермо,
нахилить корпус і крутитиме ногами педалі в такт каденсу. Якщо файлу немає — використовується вбудований велосипедист: Microsoft Rocketbox `Sports_Male_04` (MIT, `default-rider/`),
з перефарбованою формою (джерсі вашого кольору зі смугою, чорні шорти).

Перевірено на скелетах Mixamo (`mixamorig:LeftUpLeg / LeftLeg / LeftFoot`) і KayKit (`upperleg.l / lowerleg.l`);
також розпізнаються назви Blender/Rigify (`thigh.L / shin.L`), Unity Humanoid (`LeftUpperLeg / LeftLowerLeg`)
і 3ds Max Biped (`Bip01 L Thigh / Bip01 L Calf`, напр. Microsoft Rocketbox).
Якщо в моделі є анімація педалювання (назва кліпу містить cycle / bike / pedal / ride), програється вона.

## Де взяти модель

**Sketchfab** — https://sketchfab.com/search?features=downloadable&type=models&q=rigged+character
Фільтри: *Downloadable*, ліцензія *CC Attribution* або *CC0*. Кнопка Download → **glTF / GLB**. Обирайте моделі з
позначкою *Rigged*. Атрибуцію автора запишіть у `assets/CREDITS.md`.

**Mixamo** (безкоштовно з акаунтом Adobe) — https://www.mixamo.com → Characters → оберіть персонажа →
Download: *FBX Binary (.fbx)*, *T-Pose* → перейменуйте файл на `rider.fbx` і покладіть сюди. Текстури вже всередині.
Умови Mixamo дозволяють використовувати персонажів у своїх проєктах, але не поширювати самі файли моделей —
тому `rider.fbx` і `rider.glb` додано в `.gitignore` (для моделі з CC0 можна закомітити: `git add -f`).

## Тонке налаштування (необов’язково) — `rider.json`

```json
{
  "height": 1.75,
  "rotateY": 90,
  "jerseyMaterials": ["Shirt"],
  "shortsMaterials": ["Pants"]
}
```

- `height` — зріст у метрах (за замовчуванням 1.75);
- `rotateY` — поворот у градусах, якщо автоматика розвернула персонажа неправильно;
- `hipsX` / `hipsY` — де стоїть таз відносно каретки, м (за замовчуванням −0.2 і 0.97). Підбирайте так, щоб коліно
  внизу педалі було зігнуте до ~150°, а сідниці лежали на сідлі (сідло ≈ 1.03 м);
- `torsoLean` — нахил спини над горизонталлю, градуси (за замовчуванням 28; більше — рівніше, руки менш зігнуті);
- `neckAngle` / `headAngle` — нахил шиї й голови над горизонталлю, градуси (52 і 70 за замовчуванням;
  більше — голова вище, погляд уперед на дорогу, а не на кермо);
- `armLength` — довжина рук відносно моделі (1 — як є). Для низької гоночної спини руки часто задовгі й
  лікті підгинаються — тоді менше 1 (у вбудованого райдера 0.86);
- `clavicle` — куди повертати ключиці: `{"out": 0.72, "fwd": 0.5, "up": -0.1}` за замовчуванням; менше `fwd` і від'ємніше `up` — плечі
  нижче й далі від керма (менше «горба», рука тягнеться вперед);
- `bodyKit: true` — для «голого» базового тіла: намалювати на ньому велоформу (джерсі, шорти, шкарпетки, взуття);
- `vertexColors: false` — ігнорувати кольори вершин моделі (у Quaternius там маски шейдера, з ними шкіра чорна);
- `helmet: false` — не вдягати шолом (за замовчуванням вдягається, а волосся моделі ховається під ним);
- `helmetScale` — розмір шолома, якщо він завеликий чи замалий (за замовчуванням 1);
- `glasses: false` — без окулярів (за замовчуванням спортивні окуляри з дзеркальною лінзою);
- `helmetColor` — колір шолома (за замовчуванням білий, смуга — у колір джерсі);
- `armSlim` — наскільки звузити руки й рукави (1 — як у моделі, за замовчуванням 0.8; корисно для об’ємних светрів і худі);
- `sleeve` — довжина рукава джерсі: частка плеча (за замовчуванням 0.6, з окантовкою кольору акценту); `false` — лишити рукави моделі як є;
- `sockHeight` — висота шкарпеток: 0 — щиколотка, 1 — коліно (за замовчуванням 0.42); `false` — лишити шкарпетки моделі як є;
- `jerseyMaterials` / `shortsMaterials` — назви матеріалів або частин моделі (mesh) одягу, які перефарбувати в кольори джерсі й шортів
  (без цього матеріали з назвами на кшталт *shirt / top* і *pants / shorts* перефарбовуються автоматично).


# Модель велосипеда (необов’язково)

Покладіть **`bike.glb`** — будь-який велосипед у форматі glTF Binary (наприклад, з Sketchfab:
Download 3D Model → *glTF Binary (.glb)*). Power Up розверне його по ходу руху, підбере розмір під посадку
велосипедиста й поставить на дорогу; частина з назвою на кшталт *crank / pedal* крутиться в такт каденсу.
Якщо файлу немає — використовується вбудований шосейний велосипед.

Моделі з ліцензією CC Attribution можна комітити — допишіть автора й посилання в `assets/CREDITS.md`.

Необов’язковий `bike.json`:

```json
{ "node": "Bike_02", "rotateY": 180, "length": 1.68, "offset": [0, 0, 0], "crankNode": "Cranks" }
```

- `node` — назва однієї моделі, якщо у файлі їх кілька (набір велосипедів);
- `rotateY` — розворот у градусах, якщо велосипед їде задом наперед (спробуйте 180);
- `length` — довжина від колеса до колеса, м; `offset` — зсув [x, y, z], м;
- `crankNode` — назва частини з шатунами, якщо автоматично не знайшлася.
