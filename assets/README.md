# Моделі для 3D-графіки

**Природа** (`nature/`) і **глядачі** (`rider/rider.gltf`, `fans/`) — CC0-моделі Quaternius у спільному мультяшному стилі,
див. `CREDITS.md`. Без цих тек сцена повертається до вбудованих форм.

## Манекен-велосипедист (головний райдер)

Якщо є `rider/dummy.gltf`, застосунок садить на велосипед **манекен із твердих частин** (стегна, гомілки,
плечі, передпліччя, кисті, торс), що повертаються в суглобах і не деформуються. Посадка, руки на ріжках
і ноги на педалях беруться з геометрії велосипеда. Файли не в репозиторії (ліцензію джерела не перевірено),
їх готують скрипти:

- `python3 tools/prepare_dummy.py "<тека з Drivetrain_V2_gltf_.gltf>"` → `rider/dummy.gltf` + `dummy.bin`
  (манекен із «Drivetrain V2», спрощений до low-poly й розмічений під велоформу);
- `python3 tools/prepare_head.py "<завантажений .glb>"` → `rider/head.glb` (голова з обличчям, шоломом,
  окулярами й ремінцями — «Stylized Cycling Helmet» із Summer Engine). Без неї манекен отримує шолом із `js/helmet.js`.

Тонке налаштування — `rider/dummy.json` (усе необов'язкове): `hips` `[вперед, вгору]` — сідниці на сідлі;
`back` — нахил спини (°); `grip` — кисть відносно ріжка; `fist` — загин пальців; `thigh` — товщина стегон;
`footZ`, `kneeOut`, `ankleOffset` — стопи й коліна; `headPitch`, `headScale`, `headInset`, `collarCut` — голова й комір;
`colors` — кольори (`skin`, `shoe`, `sole`, `sock`…). Без манекена використовується персонаж нижче.
Сховати райдерів і лишити тільки велосипеди: `?rider=0` в адресі.
