# Power Up

Простий віртуальний велотренажер у браузері — легка альтернатива великим платформам для тренувань удома.

## Що вміє

- **Підключення пристроїв через Bluetooth** прямо з браузера:
  - смарт-тренажери з протоколом **FTMS** (сучасні Wahoo, Tacx, Elite, Saris, JetBlack тощо) — потужність, каденс і **керування опором**;
  - старі **Wahoo KICKR v1/v2, SNAP, CORE** без FTMS — через власний протокол Wahoo (ERG і нахил);
  - вимірювачі потужності (**Cycling Power**) — потужність і каденс;
  - пульсометри (**Heart Rate**) і датчики каденсу (**CSC**) — KICKR v1 сам каденс не вимірює;
  - контролери **Zwift Ride** (а також Play / Click на прошивках без шифрування).
- **Віртуальні передачі** (24 шт.): перемикання змінює опір тренажера у вільній їзді; у тренуванні — коригує ціль ERG на ±5 Вт.
- **3 маршрути-кільця** з поворотами й рельєфом: рівнина, хвилясті пагорби, гірський перевал.
- **Вільна їзда**: тренажер імітує нахил дороги (налаштування «складність підйомів» 0–100%).
- **Структуровані тренування** в режимі **ERG** (тренажер сам тримає цільову потужність): витривалість, світ-спот, VO₂max, рамп-тест FTP.
- **Боти-суперники** з різною потужністю (Вт/кг) і таблиця відставання.
- Швидкість рахується з реальної фізики (вага, нахил, опір повітря й кочення).
- **Експорт .TCX** — завантажуйте в Strava, Garmin Connect, intervals.icu.
- **Симулятор** — можна спробувати без тренажера (повзунок або клавіші ↑/↓, пробіл — пауза).

## Кнопки контролера Zwift Ride

| Кнопка | Дія | Клавіатура |
|---|---|---|
| Перемикачі «+» / правий підрульовий / ▲ | передача важча (у тренуванні: ERG +5 Вт) | `]` |
| Перемикачі «−» / лівий підрульовий / ▼ | передача легша (ERG −5 Вт) | `[` |
| ◀ / ▶ | змінити полосу руху | ← / → |
| A | пауза / продовжити | пробіл |
| Y | пропустити інтервал тренування | `N` |

У лобі біля контролера видно назву останньої натиснутої кнопки — так легко перевірити, що все розпізнається.
Перед підключенням закрийте Zwift / Zwift Companion: контролер може бути з’єднаний лише з однією програмою.

> Протоколи Wahoo і Zwift Ride не мають публічної документації. Реалізація спирається на відкриті проєкти
> [qdomyos-zwift](https://github.com/cagnulein/qdomyos-zwift), [BikeControl](https://github.com/OpenBikeControl/bikecontrol)
> і [RideToWoosh](https://github.com/TheInGoF/RideToWoosh). Оновлення прошивки від Zwift може змінити протокол.

## Запуск

Web Bluetooth працює лише через `https://` або `localhost`, тому потрібен локальний сервер:

```bash
npm start            # або: python3 -m http.server 8000
```

Відкрийте http://localhost:8000 у **Chrome** або **Edge** (Windows, macOS, Android).
Safari і Firefox (та всі браузери на iPhone) Web Bluetooth не підтримують — там доступний лише симулятор.

Щоб користуватися з будь-якого пристрою, можна увімкнути **GitHub Pages** для репозиторію — це безкоштовний https-хостинг.

## Структура

| Файл | Призначення |
|---|---|
| `js/ble.js` | Bluetooth: FTMS, Cycling Power, Heart Rate, ERG/симуляція |
| `js/physics.js` | Модель швидкості від потужності |
| `js/routes.js` | Генерація маршрутів (висота, повороти, дерева) |
| `js/render.js` | Псевдо-3D сцена й профіль висоти |
| `js/workouts.js` | Тренування (у % від FTP) |
| `js/recorder.js` | Запис заїзду, NP, експорт TCX |
| `js/app.js` | Інтерфейс і головний цикл |
