# Power Up

Простий віртуальний велотренажер у браузері — легка альтернатива великим платформам для тренувань удома.

## Що вміє

- **Підключення пристроїв через Bluetooth** прямо з браузера:
  - смарт-тренажери з протоколом **FTMS** (сучасні Wahoo, Tacx, Elite, Saris, JetBlack тощо) — потужність, каденс і **керування опором**;
  - старі **Wahoo KICKR v1/v2, SNAP, CORE** без FTMS — через власний протокол Wahoo (ERG і нахил);
  - вимірювачі потужності (**Cycling Power**) — потужність і каденс;
  - пульсометри (**Heart Rate**) і датчики каденсу (**CSC**) — KICKR v1 сам каденс не вимірює;
  - контролери **Zwift Ride** напряму (а також Play / Click на прошивках без шифрування);
  - будь-які контролери за відкритим стандартом **[OpenBikeControl](https://openbikecontrol.org)** — зокрема через застосунок
    [BikeControl](https://bikecontrol.app/), який підключає Zwift Ride/Click/Play, Elite, Wahoo, геймпади тощо.
- **Віртуальні передачі для Zwift Cog** (24 передачі, ≈0.75–5.49): як у Zwift, тренажеру надсилається віртуальна
  окружність колеса (Wahoo `0x48`, FTMS `0x12`), тож важча передача дає більше швидкості й опору при тому ж каденсі.
  Якщо тренажер команду не приймає — автоматичний перехід на зміщення нахилу. У тренуванні перемикачі коригують ціль ERG на ±5 Вт.
  У профілі вкажіть передню зірку, на якій стоїть ланцюг (Cog = 14T).
- **10 маршрутів-кілець** з різним рельєфом і власним світом:

  | Маршрут | Довжина | Характер |
  |---|---|---|
  | Річкова набережна | 8 км | рівно, берези й річка |
  | Соняшниковий степ | 25 км | довгі прямі, ідеально для ERG |
  | Хвилясті пагорби | 12 км | луки, короткі підйоми |
  | Морське узбережжя | 15 км | пальми, пісок, море |
  | Осінній ліс | 10 км | золоті дуби, звивиста дорога |
  | Вечірні пагорби | 20 км | захід сонця, «стіни» до 8% |
  | Зимовий ліс | 9 км | засніжені ялини, снігопад |
  | Червоний каньйон | 12 км | кактуси, столові скелі, затяжний підйом |
  | Карпатський серпантин | 14 км | смереки, підйом 4–8% |
  | Гірський перевал | 16 км | підйом до засніжених вершин |
- **Вільна їзда**: тренажер імітує нахил дороги (налаштування «складність підйомів» 0–100%).
- **Структуровані тренування** в режимі **ERG** (тренажер сам тримає цільову потужність): витривалість, світ-спот, VO₂max, рамп-тест FTP.
- **Боти-суперники** з різною потужністю (Вт/кг) і таблиця відставання.
- **3D-графіка (Three.js)** у low-poly стилі: рельєф з пагорбами й долинами, ліс, паркани, море й річка, гори
  на горизонті, тіні, 3D-велосипедисти з анімацією педалювання. Світ генерується на ходу відрізками по 200 м.
  Для слабких комп’ютерів у профілі можна ввімкнути класичну 2D-графіку.
- Швидкість рахується з реальної фізики (вага, нахил, опір повітря й кочення).
- **intervals.icu**: заплановані тренування з календаря просто в списку режимів, а виконаний заїзд автоматично
  завантажується назад і позначає тренування виконаним. FTP і вага підтягуються з профілю.
- **Точний запис:** 1 запис на секунду з середньою потужністю й каденсом за цю секунду (як у Garmin), годинник заїзду
  йде за реальним часом і не зупиняється у фоновій вкладці; екран не гасне під час заїзду.
- **Експорт .FIT як у Zwift**: тип Virtual Ride (cycling / virtual_activity), 1 Гц записи потужності, каденсу,
  пульсу, швидкості, дистанції й висоти, кола на кожен інтервал тренування або коло маршруту, підсумок сесії з NP і
  роботою. Перевірено офіційним декодером Garmin FIT SDK (`npm test`). TCX теж доступний.
- **Симулятор** — можна спробувати без тренажера (повзунок або клавіші ↑/↓, пробіл — пауза).

## intervals.icu

1. В intervals.icu відкрийте **Settings → Developer Settings** і скопіюйте **API key**.
2. У лобі Power Up вставте ключ у картку **intervals.icu** і натисніть «Підключити».
   ID атлета можна не вказувати (використовується атлет, якому належить ключ).
3. Заплановані велотренування на найближчі 7 днів з’являться першими в розділі «Режим» з позначкою дня.
4. Після завершення заїзд (FIT, Virtual Ride) надсилається в intervals.icu з `paired_event_id` — тренування в календарі
   позначається виконаним. Автозавантаження можна вимкнути й надіслати вручну з екрана підсумку.

Підтримуються кроки `workout_doc`: відрізки й рампи у % FTP або ватах, діапазони (беремо середину), зони потужності,
повтори. Кроки з ціллю за пульсом/темпом або «freeride» їдуться без ERG — у режимі симуляції нахилу.
Заїзди коротші за хвилину не надсилаються.

> Ключ зберігається лише в цьому браузері (localStorage). Кнопка «Забути ключ» видаляє його.
> Ключ дає повний доступ до вашого акаунта intervals.icu — не користуйтеся ним на чужих комп’ютерах.

## OpenBikeControl

Підтримується BLE-транспорт протоколу [OpenBikeControl v1](https://github.com/OpenBikeControl/openbikecontrol-protocol)
(mDNS/TCP у браузері недоступний). Застосунок надсилає контролеру App Information (`power-up`) зі списком
підтримуваних кнопок і вібровідгук при перемиканні передач.

| ID | Дія в Power Up |
|---|---|
| `0x01` Shift Up · `0x30` Increase Difficulty · `0x10` Up | передача важча / ERG +5 Вт |
| `0x02` Shift Down · `0x31` Decrease Difficulty · `0x11` Down | передача легша / ERG −5 Вт |
| `0x03` Gear Set | пряма передача 1–24 |
| `0x12`/`0x18` Left · `0x13`/`0x19` Right · `0x1B` Steering Angle | полоса руху |
| `0x32` Skip Interval · `0x33` Pause · `0x34` Resume · `0x44` HUD Toggle | інтервал, пауза, показ HUD |

Якщо пристрій надсилає кілька дій за одне натискання (наприклад, Shift Up + Increase Difficulty), спрацьовує одна.

## Кнопки контролера Zwift Ride

| Кнопка | Дія | Клавіатура |
|---|---|---|
| Перемикачі «+» / правий підрульовий / ▲ | передача важча (у тренуванні: ERG +5 Вт) | `]` |
| Перемикачі «−» / лівий підрульовий / ▼ | передача легша (ERG −5 Вт) | `[` |
| ◀ / ▶ | змінити полосу руху | ← / → |
| A | пауза / продовжити | пробіл |
| Y | пропустити інтервал тренування | `N` |

У лобі біля контролера видно назву останньої натиснутої кнопки — так легко перевірити, що все розпізнається.
Перед підключенням закрийте Zwift / Zwift Companion: контролер може бути з’єднаний лише з однією програмою.

> Протоколи Wahoo і Zwift Ride не мають публічної документації. Реалізація спирається на відкриті проєкти
> [qdomyos-zwift](https://github.com/cagnulein/qdomyos-zwift), [BikeControl](https://github.com/OpenBikeControl/bikecontrol)
> і [RideToWoosh](https://github.com/TheInGoF/RideToWoosh). Оновлення прошивки від Zwift може змінити протокол.

## Запуск

Web Bluetooth працює лише через `https://` або `localhost`, тому потрібен локальний сервер:

```bash
npm start            # або: python3 -m http.server 8000
```

Відкрийте http://localhost:8000 у **Chrome** або **Edge** (Windows, macOS, Android).
Safari і Firefox (та всі браузери на iPhone) Web Bluetooth не підтримують — там доступний лише симулятор.

Щоб користуватися з будь-якого пристрою, можна увімкнути **GitHub Pages** для репозиторію — це безкоштовний https-хостинг.

## Структура

| Файл | Призначення |
|---|---|
| `js/ble.js` | Bluetooth: FTMS, Wahoo, Cycling Power, HR, CSC, Zwift Ride, OpenBikeControl |
| `js/intervals.js` | intervals.icu API: профіль, заплановані тренування, завантаження заїзду |
| `js/controls.js` | Розбір кнопок OpenBikeControl і Zwift Ride → дії застосунку |
| `js/physics.js` | Модель швидкості від потужності |
| `js/routes.js` | Маршрути: профіль висоти й повороти |
| `js/themes.js` | Візуальні світи маршрутів: небо, земля, фон, об’єкти |
| `js/render3d.js` | 3D-сцена на Three.js (WebGL) |
| `js/render.js` | Класична 2D (псевдо-3D) сцена й профіль висоти |
| `vendor/three/` | Three.js r160 (MIT), покладено в проєкт — інтернет під час заїзду не потрібен |
| `js/workouts.js` | Тренування (у % від FTP) |
| `js/recorder.js` | Запис заїзду, кола, NP, експорт FIT/TCX |
| `js/fit.js` | Кодувальник FIT (Garmin) |
| `js/sampler.js` | Усереднення показників сенсорів за секунду |
| `js/app.js` | Інтерфейс і головний цикл |
